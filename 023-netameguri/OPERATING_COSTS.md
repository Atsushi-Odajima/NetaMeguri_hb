# OPERATING_COSTS — 運用費の試算方法

価格は SOURCE_NOTES.md（確認日 2026-10-02）より。**為替・価格改定があるため契約前に必ず公式ページで再確認してください。** 以下は試算方法と目安で、請求額の保証ではありません。

## 費用項目
| 項目 | 単価（例） | NetaMeguriでの使われ方 |
|---|---|---|
| AI生成（Anthropic） | Sonnet 5.5: $2 / 1M input, $10 / 1M output。Haiku 4.5: $1 / $5 | Draft の整形（1件あたり入力≈素材抜粋3k + 指示0.5k tokens、出力≈0.4k tokens）、Strategist の言い換え、Voice要約 |
| AI生成（OpenAI） | GPT-5.4: $2.50 / $15、GPT-5.4 mini: $0.75 / $4.50 | 同上（選択式） |
| Embeddings | text-embedding-3-small: $0.02 / 1M tokens | 任意。既定はローカル（無料） |
| 文字起こし | gpt-4o-transcribe ≈ $0.006/分、gpt-4o-mini-transcribe ≈ $0.003/分 | 任意（字幕ファイルを入れれば0円） |
| オブジェクトストレージ | Cloudflare R2: $0.015/GB-月（egress無料）、S3: $0.023/GB-月 | 元動画・画像。「文字起こし後に元メディアを保存しない」設定で削減可 |
| DB | 初版は SQLite（サーバーのディスク）。Postgres 移行時: Supabase Pro $25/月〜、Neon Launch $0.106/CU時 + $0.35/GB-月 | |
| サーバー | VPS 等（未調査・各社料金を確認） | Node 単一プロセス |
| Jobs / Connector polling | サーバー内（追加費用なし）。SNS API 側の料金は別（例: X は投稿ごと従量課金 $0.015、URL付き $0.20 — SOURCE_NOTES §1.2、要再確認） | |
| 動画処理 | 初版は動画の焼き込み編集なし（FFmpeg 非同梱）→ 0 | |

## 計算式
```
AI生成費/月 ≈ Draft件数 × (入力tokens × 入力単価 + 出力tokens × 出力単価) / 1,000,000
            + Strategist回数 × (≈1.5k in + 0.4k out) × 単価 / 1M
文字起こし費/月 ≈ 動画・音声の分数 × 分単価
ストレージ費/月 ≈ 保存GB × GB単価（動画1時間 ≈ 1–3GB として概算）
```

## 試算例（外部AI = Sonnet 5.5、1 Draft = 3.5k in / 0.4k out → 約 $0.011）
| 規模 | ContentItem/月 | AI生成 | Strategist(×100/月) | 合計AI |
|---|---|---|---|---|
| 小 | 50 | ≈ $0.55 | ≈ $0.7 | ≈ $1.3 |
| 中 | 500 | ≈ $5.5 | ≈ $0.7 | ≈ $6.2 |
| 大 | 5,000 | ≈ $55 | ≈ $0.7 | ≈ $56 |

| 動画 | 時間/月 | 文字起こし（$0.006/分） | 元動画保存（2GB/時、R2） |
|---|---|---|---|
| 小 | 10時間 | ≈ $3.6 | 20GB ≈ $0.30/月（累積） |
| 中 | 100時間 | ≈ $36 | 200GB ≈ $3/月（累積） |
| 大 | 1,000時間 | ≈ $360 | 2TB ≈ $30/月（累積） |

- ローカル抽出エンジンのみ（既定）なら AI・embedding 費は 0。
- Workspace 設定の「月の上限（USD）」で外部AI費を上限管理（超過時はローカルに自動フォールバック）。
- 実際の token 数は素材の長さ・tokenizer（Claude 4.7以降は約30%多くカウントの記載あり）で変動します。
