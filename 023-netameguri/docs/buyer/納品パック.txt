NetaMeguri 納品パック（クライアント納品用ZIPの作成）

■ できること
投稿ごとに「画像＋本文＋投稿日」をまとめた、クライアント納品用のZIPファイルを作ります。
SNS運用を代行していて、投稿案をクライアントに確認・納品するときに使います。
対象は次の3通りから選べます。
  ・投稿を選ぶ（コンテンツの中から複数選択）
  ・コンテンツパック（そのPackの投稿すべて。アーカイブしたものは除く）
  ・キャンペーン（そのキャンペーンの投稿すべて。アーカイブしたものは除く）

■ ZIPの中身
  SNS納品パック_2026-10-07/        ← 作成した日付のフォルダ
    001/                           ← 投稿番号（001, 002 …。並び順で自動的に付きます）
      001_01.jpg                   ← 画像（投稿番号_画像番号）。元の画像をそのまま入れます（画質は落ちません）
      001_02.png
      投稿文.txt                    ← 投稿番号・投稿日・投稿時間・管理タイトル・画像名・投稿本文
    002/
      投稿文.txt
    投稿一覧.csv                    ← 全投稿の一覧（Excelで開けます）
    確認用一覧.html                 ← ブラウザで開くと、画像と本文を並べて確認できます

  ・投稿日・投稿時間は、予約日時（なければ公開日時）を Workspace のタイムゾーンで表示します。
    予約していない投稿は「（未設定）」になります。
  ・管理タイトルは投稿のタイトルです。タイトルがない投稿は「Threads（通常投稿）」のようにSNS名と形式が入ります。
  ・テキストファイルとCSVは、Windowsのメモ帳・Excelでも文字化けしない形式（UTF-8 BOM付き・CRLF）です。
  ・CSVは、数式として実行されないよう対策済みです（= + - @ で始まる値の先頭に ' を付けます）。
  ・確認用一覧.html は、ZIPを「すべて展開（解凍）」してから開いてください。展開前だと画像が表示されません。

■ 含まれないもの（社内情報は出しません）
コメント、レビュー・承認の履歴、AIの提案、Claim Registry、メモなどは納品パックに入りません。
入るのは「投稿番号・投稿日・投稿時間・管理タイトル・本文・画像」だけです。

■ 使い方
1. 投稿に画像を付ける
   投稿の編集画面（コンテンツ → 投稿を開く）の「画像」欄で［画像を追加］を押します。
   ・使える形式: JPG / JPEG / PNG / WEBP（1投稿10枚まで。11枚目以降は納品パックに入りません）
   ・GIF・HEIC などは納品パックに入りません。JPGなどに変換してから追加してください。
   ・画像の順番は追加した順です。外すときは画像の下の［外す］を押します。
2. 左メニューの［納品パック］を開きます。
   （コンテンツパック画面・キャンペーン画面の［納品パック］ボタンからも開けます）
3. 対象（投稿を選ぶ／コンテンツパック／キャンペーン）を選びます。
   「投稿を選ぶ」では、チェックを付けた投稿が画面の並び（投稿日時の順）で 001, 002 … になります。
4. ［内容を確認］を押すと、番号・投稿日・画像の枚数と、確認が必要な点が表示されます。
   ・投稿日が未入力 ／ 本文が未入力 ／ 画像が未登録 ／ 画像が多すぎる ／ 対応していない形式の画像
   確認が必要な点があっても、そのまま作成できます。
5. ［納品パックZIPをダウンロード］を押します。
   1件だけ作るときは、投稿の編集画面の「画像」欄の［納品パックZIP］でも作れます。

■ 権限
作成できるのは owner / admin / editor です（reviewer / viewer は作成できません）。
作成したことは監査ログに記録されます（本文は記録しません）。

■ 注意
・送る前に、確認用一覧.html で内容（誤字・画像の順番・個人情報）を確認してください。
・ZIPは圧縮しない形式で作るため、画像の合計サイズとほぼ同じ大きさになります。
