SNS Connector（各SNSとの接続と「今できること」）

■ 結論（この版の状態）
・この版では、実在のSNSアカウントには接続されていません。実際のSNSへの自動投稿は行われません。
・各SNS向けの本格的な接続部品（Threads / X / LinkedIn / Instagram / Facebook / TikTok / YouTube など）は、
  この版では実装されていません。
・WordPress（ブログ）用の接続部品は、公式ドキュメントに沿って実装済みですが、
  実在のWordPressサイトでの動作確認はまだしていません。また、この版の画面には接続ボタンがありません。
・画面にある「Sandbox」は、練習・デモ用のシミュレーションです（Threads / X / LinkedIn / Instagram）。
  Sandboxに「投稿」しても実際のSNSには何も表示されません。取得される反応の数字もテスト用の値です。
・手動投稿（本文をコピー → SNSを開く → 公開済みにする）は、すべてのSNSで使えます。

■ 画面の見方
左メニューの［SNS Connector］を開くと、SNSごとに次の表が出ます。
  「今できること」…… このWorkspaceで今使える機能
      下書き/手動投稿 ・ 投稿 ・ 予約 ・ 分析取得 ・ 読み取り ・ 削除
      「自動投稿可」または「手動投稿（Export/Reminder）」の表示
  「公式API（調査メモ）」…… 公式ドキュメントで確認できたこと（公式docsで可 / 条件付き / 未確認 / 公式APIなし）
      と、条件・必要な権限（Scope）
  「接続」…… 接続状態と［Sandboxに接続］［解除］
「公式API（調査メモ）」は、NetaMeguriがその機能を持っているという意味ではありません。
NetaMeguriで実際に使えるのは「今できること」の欄だけです。

■ 公式APIの調査結果の要約（SOURCE_NOTES.md、2026-10-02確認）
  Threads …… 投稿・分析・削除の公式APIあり。Meta のアプリ審査が必要。投稿は24時間で250件まで。
              公式の予約投稿機能は確認できず。
  X …… 投稿・分析の公式APIあり。従量課金（投稿1件ごとに課金、URL付き投稿は高額）。
         X API v2 に予約投稿はなし（広告用APIのみ）。
  LinkedIn …… 個人投稿は w_member_social。会社ページは Community Management API の申請・承認が必要。
  Instagram …… プロアカウント（ビジネス/クリエイター）のみ。アプリ審査が必要。投稿上限は資料間で記載差あり（要確認）。
  Facebookページ …… 投稿・予約・分析の公式APIあり。権限審査が必要。分析指標は入れ替え中。
  TikTok …… 審査前は非公開投稿のみ等の制限。当初は下書き送付が現実的。
  YouTube（動画/Shorts）…… アップロード・予約・分析の公式APIあり。未監査のプロジェクトは非公開に制限。
  YouTube コミュニティ投稿 …… 公式APIで作成する方法がありません（旧機能は廃止）。手動投稿のみ。
  WordPress …… REST API とアプリケーションパスワードで投稿・予約・削除が可能。標準では分析APIなし。
  ニュースレター（例: Buttondown）…… APIキーで下書き・予約・配信が可能。
※ 多くは公式ページの検索結果の抜粋で確認したもので、本文全体の確認が必要な項目があります。
※ API仕様・審査・回数制限・料金はよく変わります。利用・契約の前に必ず各公式ページで再確認してください。

【1】Sandbox で操作を試す（実SNSには接続しません）
1. ［SNS Connector］で、Threads / X / LinkedIn / Instagram の行の［Sandboxに接続］を押します。
2. 「Sandbox（シミュレーション）に接続します。実SNSアカウントには接続しません。」の確認で OK。
3. Sandboxの確認画面で「許可する」を押すと、接続済みになります。
4. 承認済みの投稿案で［API予約投稿］を試せます。投稿案の［投稿・予約］タブに
   「接続中のConnectorはSandbox（シミュレーション）です。実SNSには投稿されません。」と表示されます。
※ サーバー設定によっては Sandbox が無効になっている場合があります。

【2】接続の解除
owner / admin は、接続の行の［解除］で接続を外し、保存されたトークンを削除できます。

■ 安全面のしくみ（実装済み）
・接続情報（トークン）はサーバー内で暗号化して保存し、画面やバックアップには含めません。
・接続の期限切れが近づくとお知らせを出し、期限切れの接続は使いません。
・外部投稿の権限は editor に自動では付きません。owner / admin が個別に付与します。
・実SNSアカウントの接続や実投稿は、利用者が明示的に設定した場合だけ行う設計です。

■ 実SNSに接続したい場合
この版のままでは実SNSへの自動投稿はできません。接続部品の開発・各SNSの開発者登録・審査・
料金の確認が必要です。それまでは手動投稿（→「投稿予約と手動投稿.txt」）をご利用ください。
