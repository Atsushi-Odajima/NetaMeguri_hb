NetaMeguri 表記ゆれチェック（表記ルールの登録と、投稿案のチェック・置換）

■ できること
「YouTube と Youtube」「株式会社サンプル と (株)サンプル」のような表記のゆれを、
自分たちで決めたルール（辞書）に沿って投稿案から見つけ、正しい表記に直します。
  ・辞書は Workspace で1つ。メンバー全員の投稿案に同じルールが使われます。
  ・見つかった箇所を、前後の文と一緒に一覧表示します。
  ・1か所ずつ置換／同じ表記をまとめて置換／無視 ができます。
  ・辞書はJSONファイルで書き出し・読み込みできます（単体版「表記ゆれチェッカー」の辞書ファイルもそのまま使えます）。
※ 正しい表記を決めるのは利用者です。NetaMeguri が文章の正誤を判断したり、自動で校正したりはしません。

■ 辞書を作る（owner / admin）
1. 左メニューの［表記ゆれチェック］を開きます。
2. 「ルールを追加」に入力して［追加］を押します。
   ・正しい表記 …… 例: YouTube
   ・別表記（1行に1つ）…… 例: Youtube / youtube
   ・一致方式
       文字列一致 …… 文中のどこにあっても見つけます（部分一致）
       単語一致 …… 英数字の単語の一部は見つけません（例: 別表記 web は website の中では見つけない）
                    日本語・記号・空白は区切りとして扱います（「日本語webサイト」の web は見つけます）
   ・大文字小文字を区別 …… オフにすると Youtube / YOUTUBE / youtube をまとめて扱います
3. 一覧の「有効」のチェックを外すと、そのルールを一時的に止められます。［削除］で削除します。
4. 1文字だけの表記や、大文字小文字だけが違う別表記には注意（⚠）が表示されます。登録はできます。

■ 投稿案をチェックする（全員）
1. 投稿の編集画面で［表記ゆれ］タブを開き、［チェックする］を押します。
   （［表記ゆれチェック］画面の「下書きの表記ゆれ」から、見つかった投稿を直接開くこともできます）
2. 「検出表記 → 正しい表記：件数」と、1件ずつの一覧（行・前後の文・状態）が表示されます。
3. 直し方（editor 以上）
   ・［置換］…… その1か所だけ直します
   ・［この表記をすべて置換］…… 同じ表記をまとめて直します（無視にした箇所は直しません）
   ・［無視］…… 直さずに残します。［無視を解除］で戻せます
     （無視は、その画面を開いている間だけ保持されます）
4. 置換すると、投稿案は新しい版として保存されます。［履歴・コメント］から前の版に戻せます。
   承認済み・予約済みの投稿を置換すると、通常の編集と同じく再レビューが必要になります。
5. 本文を編集して保存していない間は置換できません。先に保存してください。

■ 見つけないもの・注意
・正しい表記そのもの、および正しい表記の一部分（例: 株式会社サンプル の中の サンプル）は見つけません。
・全角と半角（Ｙｏｕｔｕｂｅ と Youtube）、異体字（高 と 髙）は同じものとして扱いません。
  見つけたい場合は、その表記も別表記として登録してください。
・同じ別表記が別々の正しい表記に登録されている場合や、ある別表記が他のルールの正しい表記になっている場合は
 「競合」と表示されます。競合している箇所は置換できません。辞書を直してください。
・チェックの対象は本文です（タイトルは対象外）。

■ 辞書の書き出し・読み込み
・［JSONを書き出し］…… 辞書をJSONファイルで保存します（バックアップ・別Workspaceへのコピー用）。
・［辞書JSONを読み込む］（owner / admin）…… 現在の辞書を、ファイルの内容で置き換えます。
  ファイルに1か所でも問題があると読み込みを中止し、現在の辞書はそのまま残ります（理由が表示されます）。
・辞書は Workspace のバックアップにも含まれます。
