最初の素材から投稿を作る

■ この資料でできること
素材を1つ登録し、ネタ（Idea）を取り出し、SNS別の投稿案（Draft）を作って、承認するまでの流れです。
投稿そのもの（公開）は「投稿予約と手動投稿.txt」を見てください。

【1】素材を登録する
1. 画面右上の［＋ 素材を追加］（またはダッシュボードの［＋ 素材から作る］）を押します。
2. 上のタブから登録方法を選びます。
   ・［テキスト貼り付け］…… 記事・台本・商品説明・メモを貼り付け（.txt / .md ファイルの読み込みも可）
   ・［URL］…… Webページ1件の本文を取得します。クロール（他ページの巡回）はしません。
     社内ネットワークなど内部アドレスは拒否されます。取得できない場合は「本文（任意）」に貼り付けてください。
   ・［文字起こし(SRT/VTT)］…… 動画・音声の字幕ファイル（SRT / VTT / [mm:ss] 形式）を貼り付け
   ・［ファイル］…… 画像 / PDF / 音声 / 動画をアップロード
3. 「種類」「タイトル」「権利」「作成者」「公開日」を入力します。
   「権利」は、自分の素材なら「自分の素材」、許可を得たものなら「ライセンス取得済み」を選びます。
   それ以外を選ぶと、引用は短く出典付きで扱われます。
4. 必要に応じてチェックを入れます。
   ・「外部AIへの送信を許可」…… OFFにすると、この素材は抽出エンジンのみで処理されます。
   ・「Evergreen（長く再利用できる素材）」
5. ［登録して解析］を押します。素材の詳細画面に移ります。
   同じ内容の素材が登録済みのときは、その旨が表示されます。

▼ 動画・音声・PDFについての注意（この版の制限）
・動画/音声から自動で文字起こしをするボタンは、この版の画面にはありません。
  字幕ファイル（SRT/VTT）があれば貼り付けてください。後から［Transcript］タブの［文字起こしを添付］でも追加できます。
・PDFから文章を自動で読み取る機能はありません。PDFはファイルとして保存されるだけなので、
  本文は［テキスト貼り付け］で入れてください。
・聞き取れない箇所は [inaudible] のままにしてください。AIが内容を補うことはありません。

【2】解析結果を確認する
素材の詳細画面の［解析］タブで、トピック・要点・引用候補・「事実・数値の主張（要確認）」が見られます。
解析は素材の文章から抜き出す方式（抽出ベース）で、素材にない事実は作りません。
価格や数値は［Claim Registry］に登録しておくと、古い値を使ったときに警告されます。

【3】ネタ（Idea）を取り出す
1. 素材の詳細画面で［Ideaを抽出］を押します。
2. ［Idea］タブに、投稿ネタの一覧（角度＝失敗談・How-to・チェックリストなど、トピック付き）が出ます。
3. 過去のネタと似ているものがあっても、自動で統合・削除はされません（→「同じネタを防ぐ.txt」）。

【4】投稿案を作る（2通り）
A. まとめて作る（Content Pack）
   素材の詳細画面の「Content Packを作る」で各SNSの本数を確認し、［まとめて作成］を押します。
   → 詳しくは「Content Pack.txt」
B. 1つずつ作る
   1. ［ネタ (Idea)］から使いたいネタを開きます。
   2. 「Platform別Draftを作る」でSNSと角度を選びます。
   3. 先に［重複チェック］を押すと、過去のネタとの近さを確認できます。
   4. ［Draftを作成］を押すと、編集画面に移ります。

【5】編集してチェックする
1. 本文を直します。入力は自動で保存されます（「保存済み」「未保存」「保存中…」の表示を確認）。
   区切りとして残したいときは［版として保存］を押します。
2. 文字数（そのSNSの上限）が本文の下に表示されます。Xは重み付けの概算です。
3. 右側の「プレビュー」で見た目を確認します。
4. 下の［チェック］タブで、Brand Guard（禁止表現・絵文字など）、ネタ重複、再利用ルール、
   鮮度（日付や価格など古くなりやすい表現）、Claim Registry、出典を確認します。
   「ブロック項目」がある場合は、直すまで承認できません。
5. 必要なら［AIで再生成］（角度も選べます）。AIの結果は「AIの提案」として別に表示され、
   人が書いた本文は上書きされません。使うときは［提案を採用］を押します。
6. 他のSNS向けにしたいときは「別Platformへ変換」から選びます（新しい投稿案が作られます）。
   ［翻訳］は外部AIの設定が必要です（AI OFFやローカルエンジンでは翻訳しません）。

【6】レビュー・承認
1. 書いた人が［レビュー依頼］を押します。
2. owner / admin / reviewer が内容を確認し、［承認］または［修正依頼］を押します。
3. 承認後に本文を変えると、初期設定では再レビューが必要になります（［設定］で変更可）。
4. 変更の履歴は［履歴・コメント］タブで確認でき、［この版に戻す］で戻せます。

【7】次にすること
承認したら［投稿・予約］タブへ。→「投稿予約と手動投稿.txt」
