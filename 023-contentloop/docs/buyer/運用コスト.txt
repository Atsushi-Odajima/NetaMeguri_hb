運用コスト（月々かかる費用の考え方）

■ 先に結論
・初期設定（AI: ローカル抽出エンジン、ベクトル検索: ローカル）のままなら、外部AIの利用料は0円です。
  かかるのは、ContentLoop を動かすサーバー代と、データの保存領域の費用です。
・外部AI・文字起こしなどを有効にすると、使った量に応じて各サービスの利用料がかかります。
・下の価格は SOURCE_NOTES.md（確認日: 2026-10-02）の記録で、すべて米ドル（USD）・税抜の参考値です。
  価格はよく変わります。契約・見積もりの前に、必ず各社の公式価格ページで再確認してください。
・詳しい試算方法は、開発資料の OPERATING_COSTS.md を参照してください。
・ここでの金額は「試算例」です。実際の費用を保証するものではありません。

■ 費用の種類と見積もり方
【1】AIによる文章生成（外部AIを使う場合のみ）
  費用 = 呼び出し回数 ×（入力トークン数 × 入力単価 ＋ 出力トークン数 × 出力単価）÷ 1,000,000
  呼び出しが起きる操作: 投稿案1件の作成ごとに1回（Content Pack なら作る本数と同じ回数）、
  ［AIで再生成］、［翻訳］、AIアシスタントの質問、Brand Voice の下書き。
  この版の初期モデルと単価（1Mトークンあたり）:
    Anthropic: claude-sonnet-5-5（Claude Sonnet 5.5）入力 $2 / 出力 $10
    OpenAI: gpt-5.4 入力 $2.50 / 出力 $15
    （［設定］の「モデル（任意）」で変えた場合は、そのモデルの単価で計算してください）
  試算例（仮定: 1件あたり入力4,000トークン・出力600トークン。素材の長さで大きく変わります）
    Claude Sonnet 5.5 …… 約 $0.014 / 件
    GPT-5.4 …… 約 $0.019 / 件
    月 50件 …… 約 $0.7〜$1.0
    月 500件 …… 約 $7〜$10
    月 5,000件 …… 約 $70〜$95
  補足: Anthropic の価格ページには、Claude 4.7 以降は同じ文章でもトークン数が約30%多くなる旨の記載があります。
        日本語はトークン数の見積もりがぶれやすいため、少量で試して実際の数字を確認してください。

【2】ベクトル検索（「OpenAI Embeddings」を選んだ場合のみ）
  text-embedding-3-small: $0.02 / 1Mトークン
  素材1件あたり最大4,000文字程度＋ネタの文を送ります。素材1,000件でも数十セント程度の見込みです。

【3】文字起こし（サーバー管理者が有効にした場合のみ。この版の画面にボタンはありません）
  この版のコードが使うモデルは OpenAI の whisper-1 ですが、その現行価格は SOURCE_NOTES で未確認です。
  参考（OpenAI、分あたり）: gpt-4o-transcribe 約 $0.006 / gpt-transcribe 約 $0.0045 / gpt-4o-mini-transcribe 約 $0.003
  試算例（仮に $0.006/分 とした場合）: 動画10時間 約 $3.6 / 100時間 約 $36 / 1,000時間 約 $360
  字幕ファイル（SRT/VTT）を自分で用意して貼り付ける場合、この費用はかかりません。

【4】ファイルの保存
  この版は、アップロードしたファイルをサーバーのディスクに保存します。
  バックアップ用にクラウドの保存サービスへコピーする場合の参考価格:
    Cloudflare R2（Standard）: $0.015 / GB・月（毎月10GBまで無料、転送料なし）
    AWS S3（Standard, us-east-1）: $0.023 / GB・月（転送量により別途費用）
  試算例（仮定: 動画1時間 = 2GB）: 動画100時間 = 200GB → R2 約 $2.85/月、S3 約 $4.6/月
  ［設定］の「文字起こし後も元のメディアを保存する」をOFFにすると、保存量を減らせます。

【5】データベース
  この版は、サーバー上の1つのデータベースファイル（SQLite）を使います。データベースの別料金はかかりません。
  将来、マネージドのPostgreSQLへ移す場合の参考（この版はPostgreSQLに未対応）:
    Supabase: Free（DB 500MB 等の制限あり）、Pro $25/月〜
    Neon: Free あり、Launch $0.106 / CU時間 ＋ ストレージ $0.35 / GB・月

【6】サーバー（ホスティング）
  ContentLoop は常に動かしておく必要があります（予約の処理を約30秒ごとに実行するため）。
  VPS・クラウドの料金は SOURCE_NOTES では調査していません。契約するサービスの料金表で確認してください。
  必要な環境: Node.js 22.13 以上。

【7】SNSの公式API（この版では未接続。将来接続する場合）
  X API は従量課金で、投稿1件 $0.015、URLを含む投稿は1件 $0.20（2026-04-20以降の価格として記録）。
  ブログやニュースレターへのリンクを付ける運用では費用が大きくなります。
  他のSNSのAPI利用料は SOURCE_NOTES で未確認です。

【8】その他
  ・動画の編集・変換（FFmpeg 等）はこの版に含まれないため、その処理費用はかかりません。
  ・ChatGPT・Claude などのAIアプリの月額料金は、ContentLoop とは別に各社と契約が必要です。

■ 費用を抑える・上限を決める
1. ［設定］→「AI」の「月の上限（USD）」（初期 $20）を設定します。上限に達すると外部AIを使わずローカル処理になります。
   ※ この上限の計算は、ContentLoop 内の概算単価（Anthropic 入力$2/出力$10、OpenAI 入力$2.50/出力$15）によるものです。
     実際の請求額とは一致しない場合があります。各社の管理画面でも利用上限を設定してください。
2. 同じ欄に「今月の利用: $○ / $上限」が表示されます。少量で試し、1件あたりの実費を確認してから本格利用してください。
3. Content Pack の本数を必要な分だけにします。
4. 外部AIが不要な期間は「AIを使う」をOFFにします（外部送信0件・利用料0）。
