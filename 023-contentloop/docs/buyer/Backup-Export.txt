Backup / Export / Import（データの書き出し・バックアップ・取り込み）

■ この画面
左メニューの［Import/Export］（画面名「Import / Export / Backup」）にまとまっています。
書き出し・バックアップには、それぞれの権限が必要です（バックアップと復元は owner / admin）。

【1】Export（書き出し）
「Export」欄のボタンで、投稿案をダウンロードできます。
  ［CSV］…… 表計算ソフト用。数式として実行されないよう対策済み（数式インジェクション対策）
  ［JSON］…… 他のシステムへの移行用
  ［MD］…… Markdown 形式
  ［TXT］…… テキスト形式
  ［Platform別コピー用ZIP］…… 承認済み・予約済みの投稿を、SNS別に貼り付けやすい形でまとめたZIP
ほかの画面からも書き出せます。
  ・Content Pack 画面の［ZIPで書き出し］…… そのPackの投稿案（1件1ファイル＋一覧）
  ・キャンペーン詳細画面の［カレンダーCSV］…… キャンペーンの予定表
  ・素材の［Transcript］タブの［SRT］［VTT］…… 文字起こしの字幕ファイル

【2】Backup（バックアップ）
1. 「Backup / Restore」欄の［Workspaceをバックアップ］を押すと、ZIPファイルがダウンロードされます。
2. 中身: Workspaceの設定、Brand、素材（本文・文字起こしを含む）、ネタ、投稿案と版の履歴、
   キャンペーン、予約、反応の記録、Claim Registry、監査ログ、Connectorの設定情報など。
   manifest.json に schemaVersion / appVersion / checksum（改ざん・破損の確認用）が入ります。
3. 含まれないもの:
   ・SNS接続のトークン（復元後に再接続が必要です）
   ・アップロードしたメディアファイル（画像・音声・動画・PDFの実体）
     → サーバーのデータフォルダ内のファイル保存領域を、別途コピーしてバックアップしてください。
   ・検索用ベクトル（復元時に作り直します）
4. バックアップには素材の本文などが含まれます。安全な場所に保管してください。
5. 定期的に（例: 週1回、大きな作業の前）取得することをおすすめします。自動バックアップ機能はありません。

【3】Restore（復元）
1. 復元先は「空のWorkspace」である必要があります（素材・ネタ・投稿案・キャンペーンが1件もないこと）。
   例: 新しくアカウントを作ると作られる最初のWorkspace。
2. 復元したいWorkspaceを開き、「空のWorkspaceへ復元」でバックアップZIPを選びます。
3. checksum が一致しない（壊れている）場合や、新しいバージョンで作られたバックアップは復元を中止します。
4. 完了すると「復元しました: …」と件数が表示されます。
5. 復元後にすること:
   ・SNS Connector を再接続する
   ・メディアファイルを別途コピーで戻す
   ・内容をいくつか開いて確認する

【4】過去投稿の Import（CSV取り込み）
ContentLoopを使う前の投稿を取り込むと、ネタとして記録され、重複チェックの対象になります。
反応の数字も一緒に取り込めます。
1. 「過去投稿をImport（CSV）」でCSVファイルを選ぶか、内容を貼り付けます。
   例の列: platform,date,text,likes,views
2. CSVにSNSの列がない場合は「Platform列がない場合」でSNSを選びます。
3. ［プレビュー］を押します（この時点では保存されません）。
4. 列の対応付け（text / platform / publishedAt / url / likes / views / impressions / comments /
   shares / saves / clicks）を確認・変更します。
5. プレビュー表の「重複」欄に、取込済み・似ているネタが表示されます。
6. ［確定］を押すと、「作成 ○件・スキップ ○件・エラー ○件」と表示されます。
   取り込んだ投稿は「Import」由来の公開済み投稿として記録されます。
※ 各SNSの公式な書き出しデータの形式はSNSごとに違います。必要に応じて列名を整えてから取り込んでください。
※ 取り込むのは自分のアカウントの投稿だけにしてください。

【5】UTMリンク作成
URL・source・campaign を入れて［作成］を押すと、効果測定用のUTM付きURLを作れます。
（クリック数の自動集計はしません）

■ 注意
・書き出したファイルや取り込むCSVは、他人と共有する前に内容（個人情報など）を確認してください。
・ZIPの中のファイル名はContentLoopが自動で付けるため、不正なパスを含むことはありません。
