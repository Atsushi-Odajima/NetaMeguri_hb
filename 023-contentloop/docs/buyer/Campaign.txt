Campaign（キャンペーン：一連の投稿をまとめて計画する）

■ Campaign とは
商品の発売、イベント告知などの目的に合わせて、複数の投稿を「流れ」として計画・管理する機能です。
作成すると、次の8段階の下書き計画（シーケンス）が自動で並びます。
  Teaser → Problem → Story → Demo → Release → Use Case → FAQ → Reminder
これは「たたき台」です。最適な計画であることは保証しません。日付や内容は自由に見直してください。

【1】キャンペーンを作る
1. 左メニューの［キャンペーン］を開きます。
2. 「新しいキャンペーン」に入力します。
   名前（必須）/ 商品 / 開始日 / 終了日 / 目的 / 対象
   Key Message（1行に1つ）…… 伝えたい要点
   Channel …… 使うSNS（チェックを付ける）
   使う素材 …… このキャンペーンで使う素材（チェックを付ける）
3. ［作成して8段階のDraft計画を作る］を押します。キャンペーンの詳細画面に移ります。

▼ 日付の割り振り
・開始日〜終了日の間に8段階を均等に並べます。
・日付を入れない場合は、今日から14日間で並べます。
・SNSはChannelで選んだものを順番に割り当てます（未選択ならThreads / X / LinkedIn）。
・Key Messageも段階ごとに順番に割り当てます。

【2】各段階の投稿案を作る
1. 詳細画面の「シーケンス（Teaser → Reminder）」に段階・予定日・SNSが並びます。
2. 投稿案がまだない段階には［Draftを作る］ボタンがあります。押すと、
   「使う素材」から取り出したネタの中から、段階に合う角度（例: Demo＝How-to、FAQ＝FAQ）や
   Key Messageに近いものを選んで投稿案を作ります。
   ※ 先に素材の［Ideaを抽出］をしておいてください。ネタがないと作れません。
3. 作った投稿案は、リンクから編集画面を開いて、通常どおりチェック・承認します。
4. 計画を作り直したいときは［未作成ステップを再計画］を押します。
   投稿案がまだない段階だけが作り直され、作成済みの段階は残ります。

【3】Campaign Guard（確認用のヒント）
詳細画面の「Campaign Guard」に、次のような確認事項が出ます。
  ・同じネタが7日以内に複数回使われている
  ・内容が非常に近い投稿がある
  ・Key Messageを扱う投稿がない
  ・特定のSNSに偏っている（投稿が4件以上のとき、6割を超える場合）
  ・予定Channelで未使用のSNSがある
  ・「使う素材」がまだ使われていない
  ・投稿案が未作成のステップがある
これらはヒントです。表示がなくても、計画が良いとは限りません。

【4】カレンダーで見る・書き出す
・［カレンダー］には、投稿案がまだない段階が「予定: 段階名」として表示されます。
  予約した投稿は日時付きで表示されます（⚡＝API予約、✋＝手動投稿リマインダー）。
・詳細画面の［カレンダーCSV］で、キャンペーンの予定をCSVでダウンロードできます。

【5】AIアシスタントで不足を聞く
［AIアシスタント］で「Campaignで足りない投稿は？」と聞くと、進行中のキャンペーンの確認事項をまとめて表示します。

■ 注意
・投稿の公開は、各投稿案の［投稿・予約］タブから行います（→「投稿予約と手動投稿.txt」）。
・キャンペーンの作成・計画の作成は［監査ログ］に記録されます。
