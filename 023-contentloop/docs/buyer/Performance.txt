Performance（反応の記録と効果分析）

■ この機能でできること
公開した投稿の反応（表示回数・いいね・コメントなど）を記録し、
SNSごとのまとめと「どんなネタ・角度・形式の反応が良い傾向か」を表示します。
記録は、次の投稿案づくりや再利用候補の判断に使われます。

■ 大事な前提
・表示されるのは「傾向（相関）」です。原因（因果関係）を示すものではありません。
・過去の反応から、将来の成果（伸びる・フォロワーが増えるなど）は保証できません。
・指標の定義はSNSごとに違います。そのため、SNSをまたいだ合計は出しません。
・件数が少ないと偶然の差が大きく出ます。「件数不足」の表示がある行は参考程度にしてください。

【1】反応を記録する（手入力）
1. 公開済みの投稿案を開き、［反応］タブを開きます（公開済みのものだけ記録できます）。
2. 「反応の記録」に数値を入れます（空欄のままでも構いません）。
   impressions（表示回数）/ views（再生・閲覧）/ likes / comments / shares / saves / clicks
3. 期間を選びます: 24h / 7d / 30d / custom（公開後どのくらいの時点の数字か）
4. ［記録］を押します。「スナップショット」に履歴として追加されます（上書きはされません）。
   数字は各SNSのアプリや管理画面（インサイト）で確認して入力してください。

【2】過去投稿をCSVでまとめて取り込む
［Import/Export］→「過去投稿をImport（CSV）」で、本文と一緒に likes / views / impressions /
comments / shares / saves / clicks の列を取り込めます（→「Backup-Export.txt」）。

【3】Connectorから取得する（この版の制限）
［Connectorから取得］ボタンは、API経由で公開した投稿（API確認済み）にだけ表示されます。
この版で使えるのはSandbox（シミュレーション）だけで、Sandboxから取得される数値は
テスト用に機械的に作られた数字です。実際の反応ではありません。分析の判断には使わないでください。

【4】効果分析の画面
1. 左メニューの［効果分析］を開きます。
2. 右上で期間（過去30日 / 過去90日 / 過去180日 / 過去365日）を選びます。
3. SNSごとのカードに次が表示されます。
   ・投稿件数（うち指標あり件数）
   ・指標ごとの合計（そのSNS内だけの合計）
   ・median engagement（反応率の中央値）
   ・そのSNSでの指標の意味（例: Instagramの views は旧 impressions 等）
   反応率 =（likes + comments + shares + saves + clicks）÷ 表示数
   表示数は impressions → views → reach の順で、入力があるものを使います。表示数がない投稿は計算に入りません。

【5】傾向（Feedback Loop）
同じ画面の「傾向（Feedback Loop）」で、切り口をタブで選びます。
  Topic / Angle / Format / Platform / 長さ / CTA / Hook
それぞれのグループごとに、件数 n と反応率の中央値を並べます。
・n が3未満のグループには「件数不足」と表示されます。
・上部の一文（例: 「過去90日、Topic「○○」は他よりmedian engagementが高い傾向でした（n=…）。
  相関であり因果関係や将来の成果は保証しません。」）も、相関の要約です。
  十分な件数で差がない場合は「目立つ差は確認できませんでした」と表示されます。
・下部に期間・公開件数・指標あり件数・分母（何で割ったか）が表示されます。

【6】記録がほかの機能に使われる場面
・反応率が同じSNSの他の投稿（3件以上）の中央値の1.5倍以上だと、その投稿は
  High Performer（反応が良い投稿）として扱われ、一定期間後に再利用候補に出ます。
  （→「過去投稿を再利用する.txt」）
・［AIアシスタント］の提案で「反応が良い傾向のTopic」として参考にされます。
・［ライブラリ検索］で「過去に反応が良かった〜」と検索できます。

■ よくある質問
Q. フォロワー数の変化やUTMのクリックも記録できますか？
A. この版の手入力欄は上の7項目です。リンクのクリック計測用に、［Import/Export］の
   「UTMリンク作成」でUTM付きURLを作れますが、クリック数の自動集計はしません。
   計測結果は各アクセス解析ツールで確認し、clicks に入力してください。
